# NumPy Practice

This folder contains small NumPy notebooks used to practice array creation, manipulation, and numerical operations.

## Topics covered

- Creating arrays with `numpy.array()`
- Understanding scalars, 1D arrays, 2D arrays, and 3D arrays
- Inspecting array attributes such as `ndim`, `shape`, `size`, `dtype`, and `itemsize`
- Reshaping arrays for different data layouts
- Performing mathematical operations and aggregations
- Preparing numeric data structures for machine learning workflows

## Files in this folder

- [arrays.ipynb](./arrays.ipynb) — examples of NumPy arrays and array attributes
- [operations.ipynb](./operations.ipynb) — mathematical operations, reshaping, and aggregation examples

## Getting started

```bash
pip install numpy
```

Open the notebooks in Jupyter or VS Code to run the examples interactively.

## Purpose

NumPy is a core scientific computing library in Python. It provides efficient multidimensional arrays and fast numerical operations, making it essential for data analysis, machine learning, and scientific computing.
